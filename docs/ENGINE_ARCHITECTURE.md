# PLUTUS Engine Architecture

## Engine Stack

### P01 — Volume Intelligence
Foundation for relative volume, abnormal participation, effort-versus-result, expansion, contraction, climax, absorption, and low-participation states.

### P02 — VWAP
Session/daily/weekly/monthly and anchored VWAP logic with deviation bands and value-state interpretation.

### P03 — Volume Profile
Session, rolling, anchored, and later composite profile research/prototypes. Core outputs: POC, VAH, VAL, HVN, LVN.

### P04 — Value Analysis
Interprets value migration, POC migration, acceptance/rejection, overlap, separation, and auction state.

### P05 — Institutional Zones
OB, BB, FVG and IFVG structures enriched with volume/value/VWAP evidence rather than treated as standalone SMC drawings.

### P06 — Divergence
Price versus volume, RVOL, POC/value, VWAP and selected momentum divergence.

### P07 — Confluence
Combines engine states into participation/regime classifications.

### P08 — Visual / UX
Controls chart density, dashboards, labels, profiles, zones, and diagnostic views.

### P09 — Signals
Setup and signal generation built only after upstream engines are independently validated.

## Integration Rule
Prototype engines must remain isolated until their state outputs, invalidation rules, edge cases, and non-repainting behaviour are documented and tested.
