# P01 — Volume Intelligence

Foundation prototype area for volume normalization, relative volume, abnormal participation, effort-versus-result, absorption, exhaustion, expansion, contraction and related diagnostic states.

## Development stages

- `P01.0` — baseline volume normalization and data-quality diagnostics
- `P01.1` — effort-versus-result classification
- `P01.2` — footprint enhancement using native Pine v6 footprint data where available
- `P01.3` — consolidated participation-state engine

## Core requirement

P01 must remain functional without footprint access. Native footprint data is an enhancement layer, not a hard dependency.
